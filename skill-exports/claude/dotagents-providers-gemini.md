# dotagents-providers-gemini

Deploy dotfiles for Gemini using the Gemini provider in dotagents. Use when configuring Gemini agent commands, skills, or instructions.

## Instructions

# Dotagents Providers — Gemini

## Deploy Gemini

```bash
dotagents deploy
```

## Add Gemini Target

