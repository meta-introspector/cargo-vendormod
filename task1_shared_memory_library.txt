TASK 1: CREATE THE LOW-LEVEL SHARED-MEMORY LIBRARY (dashlm_shared_index)

Goal:
  Provide a safe, reusable Rust wrapper around LibAFL’s UnixShMem (or MmapShMem) that implements a fixed-size hash table + bump-allocated value heap, zone-based hashing, and optional CPU/GPU access logs.

Steps:
  1. Create a new crate under `cargo-vendormod/dashlm_shared_index`.
  2. Dependencies:
        - libafl_shmem = { path = "../../../dasl/rust/ipld-core/LibAFL/crates/shmem_providers" }
        - siphash = "1.3"
        - bincode = "1.3" (or postcard = "0.7")
        - once_cell = "1.19"
  3. Implement memory layout:
        - Header (64 bytes): magic, version, zone_count, slot_count, value_heap_offset, value_heap_size, value_heap_used, reserved.
        - Slot array: each slot 16 bytes (key_hash u64, value_len u32, value_offset u32, mem_type u8, zone u8, padding u16).
        - Value heap: growable region after slot array (bump allocator).
        - Access logs (optional): two circular buffers for CPU/GPU accesses.
  4. Provide public SharedIndex struct with methods:
        open_or_create, store, get, access, cpu_accesses, gpu_accesses, check_conflicts, zone_distribution.
  5. Write unit tests for store/retrieve, zone calculation, concurrent readers, access logging.
  6. Ensure builds with `nix develop -c cargo build --release`.

Skills needed:
  - hermes-agent (environment setup)
  - nix-flakes / nix (reproducible builds)
  - cargo-vendormod-testing (unit tests)
  - (rust-clap-command-verification not needed for this task)
